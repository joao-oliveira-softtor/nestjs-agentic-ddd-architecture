Use the decorated code as the source of the specification. Read `agentic.config.ts` (or the given configuration) and the module's generated skill for paths, rules and specific contracts. This skill is authored and shared; the `<module>-dev` skills and the runtime skills are generated by the compiler.

Load only the references you need:

- [Authoring](references/authoring.md): declare or change the domain, schemas and proposals.
- [Manager](references/manager.md): prepare contracts and coordinate sequential execution.
- [Executor](references/executor.md): execute a packet without changing the specification, including tactical items (value object, port) and infrastructure items (adapter).
- [Domain executor](references/executor-domain.md): a `domain` item in an isolated context, with only the packet.
- [Reviewer](references/reviewer.md): review the diff against the contract and the gates, without editing.
- [Orchestration](references/orchestration.md): experiment that spreads items across model tiers by layer, with escalation and telemetry; the default is the `inherit` model.
- [Installation](references/installation.md): install/check local or global links and adapters.
- [Tutorial](references/tutorial.md): practice in an isolated tasks workspace (or `--tutorial matriculas`).

Keep stable invariant IDs and public contracts. Do not edit generated artifacts; change the decorated source and compile. A pending body uses the literal call `notImplemented()`. Tests use `covers` with real IDs and check behaviour.

When implementing bodies, keep the lines of the following declarations by using the space prepared in the skeleton: the current compiler puts source coordinates in the generated files. Without enough space, return the item to the manager to prepare/recompile before dispatching again.

An item requires `verify --item` with the original hash and the result `done`. A change ends with `verify NNNN`: `done` completes it, `needs-human` exposes pending manual acceptance. A static query never certifies `done`. Do not confuse a successful `compile` (applies/archives declarations) with finished implementation.

Language: reply to the user in the user's language. Never translate identifiers, invariant IDs or business text (`text`, `description`, `instructions`, proposals); keep them exactly as written.
