# Release v0.3.0

Publica as skills e o tutorial do Plano 5, o runner do Plano 6 e o ciclo #17–#20. A versão pública escolhida é v0.3.0; não existe release intermediária v0.2.0. O [changelog](../../CHANGELOG.md) descreve as entregas e o [roadmap](../ROADMAP.md) mantém os Planos 7–8 como próximos trabalhos.

## Demonstração reproduzível

Requer Git, Bun 1.4.2 e Linux com bubblewrap para os testes do runner. O clone completo conserva os SHAs históricos referenciados pelos manifestos.

```bash
git clone https://github.com/joao-oliveira-softtor/nestjs-agentic-ddd-architecture.git
cd nestjs-agentic-ddd-architecture
git checkout v0.3.0
bun install --frozen-lockfile
bun run agentic compile --check
bun test examples/orders/test/operator.test.ts
bun run skills:install --check
bun run skills:example --root /tmp/agentic-tasks-new
```

O tutorial exige destino novo. Os três E2E de orders exercitam criação/confirmação e cancelamento com aprovação negada/concedida usando FakeLlm e tools reais. [Tutorial autoral](../../skills/agentic-ddd/references/tutorial.md).

## Avaliações publicadas

- [#17 — certificação](../superpowers/validation/2026-10-10-evals-17/real/README.md): cinco packets aceitos e verify 0001 done para ambos os agentes; perguntas 4/5 Codex e 3/5 Cursor, sem limiar extra de acurácia.
- [#18 — 20 casos adicionais](../../evals/skills/orders.extended.yaml): dez dev/dez runtime, incluindo casos inválidos, com julgamento estrito e argumentos completos validados por AJV.
- [#19 — regressões completas](../../test/evals-run.test.ts): controle positivo, correção fresca, 19 defeitos de corpos rejeitados por oráculos privados e quatro estados de falha. Não demonstra resistência adversarial.
- [#20 — seis runs independentes](../superpowers/validation/2026-10-10-evals-20/real/README.md): cobertura 150/150, Codex 72/75 e 3/3 certificações, Cursor 70/75 e 2/3. O run Cursor parcial preserva rejeição de submissões, dependente bloqueado e criação independente aceita. 184 sessões/76,8 minutos, dentro do orçamento autorizado.

As fontes congeladas dos runs são históricas e permanecem identificadas pelos SHAs completos nos manifestos. A publicação da release não reexecuta inferência. Modelos/versões observados, todas as tentativas, configurações efetivas, hashes e reproduções offline estão nos relatórios.

Para recalcular a comparação sem adapters de inferência:

```bash
bun run evals:aggregate --campaign evals/campaigns/cycle-20/index.json --out /tmp/cycle-20-aggregate-new
```

JSON, Markdown e manifesto foram reproduzidos byte a byte em dois destinos novos. Métricas derivam das evidências; resultados parciais e denominadores planejados são explícitos. Tokens Codex disponíveis são somados; medições Cursor incompletas e custos permanecem indisponíveis. Sem ranking ou significância estatística.

## Verificação e distribuição

A preparação exige os seis checks abaixo sobre a árvore publicada; seus resultados finais, SHA da árvore/commit e CI são registrados no asset `validation-v0.3.0.json` da release, junto do agregado e de hashes verificáveis.

```bash
bun test
bun run typecheck
bun run lint
bun run build
bun run agentic compile --check
bun run skills:install --check
```

Os [checks anteriores do ciclo](../superpowers/validation/2026-10-10-evals-19/ci-scope/README.md) registram 456 testes e 14 snapshots. CI e testes padrão permanecem offline. O framework público, orders, dataset original e artefatos históricos são preservados.

Distribuição pelo código-fonte GitHub; `package.json` permanece privado. O build inclui `dist/main.js.map`, necessário ao runtime empacotado. Provider real de LlmPort e CLI interativa permanecem nos Planos 7–8. A change orders 0002 mantém `needs-human` pelo critério manual G6 do exemplo; a release não presume essa aprovação.
